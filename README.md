# Buuni

Buuni is a Somali-first social gaming platform. Step 1 establishes the public web foundation for a future multi-game experience.

## Stack

- Next.js 16.3.3
- React 19.2.1
- TypeScript 7.0.2
- Tailwind CSS 4.3.3
- App Router

## Run locally

Requirements: Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Available checks

```bash
npm run lint
npm run typecheck
npm run build
```

No database, authentication, multiplayer, game logic, payments, ads, or external APIs are included in this foundation.
